# JavaPath — Learn Java to Job-Ready

A self-paced, single-page learning platform that teaches Java from core fundamentals
through to being job-ready as a Junior Java Developer. Lessons are followed by quizzes;
passing a topic quiz (70%+) marks it complete and unlocks the next topic.

## How to run

1. Open the folder containing this README.
2. Double-click **`index.html`** (or right-click → Open with your browser).

No build step, no npm, no server, no CDN. Everything runs from `file://`.

Supported browsers: any modern Chromium, Firefox, or Safari. Progress is stored in
`localStorage` under the `javapath.*` namespace.
